# Habit Garden

Hábitos viram plantas que crescem com a sequência de dias; semana clicável, metas e persistência.

**Stack:** React + TypeScript + esbuild + Jest + React Testing Library. Site estático: abra `index.html` (ou GitHub Pages); o bundle pronto está em `dist/`.

**Rodar:** sirva a raiz do portfólio (`python3 -m http.server 8080`) e abra `/project_053/index.html`.

**Buildar:** `npm install && npm run build` (código em `src/`, saída em `dist/`). **Testes:** `npm test`.
