# 074 · Oficina (Assistente IA para devs, DEMONSTRAÇÃO)
React + TypeScript + Tailwind. UI de chat com 4 agentes, ferramentas ligáveis, passos de execução e streaming.

**Todas as respostas são SIMULADAS** (`src/sim.ts`: modelos de texto + heurísticas por palavra-chave). Nenhuma API de IA é chamada e nenhuma chave é usada. Para ligar um modelo real, substitua `plan`/`answer` por uma chamada ao seu backend (nunca coloque chaves no front-end).

```
npm i && npm run build
```
