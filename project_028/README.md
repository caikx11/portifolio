# Aplicativo de Leitura de Notícias

Este projeto implementa um aplicativo de leitura de notícias com as seguintes funcionalidades:

- Busca de notícias por texto
- Filtragem por categoria (Tecnologia, Esportes, Política, Entretenimento, Saúde)
- Visualização detalhada de notícias
- Design responsivo
- Carregamento simulado de notícias (para demonstração)

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)

## Como Executar

Simplesmente abra o arquivo `index.html` em qualquer navegador web moderno.

## Funcionalidades Implementadas

1. Interface de busca e filtragem
2. Exibição de notícias em formato de cartões
3. Visualização detalhada de notícias em modal
4. Navegação por categorias via barra lateral
5. Design responsivo para diferentes tamanhos de tela
