Parâmetros da Mola

Equação: m·x'' + b·x' + k·x = 0

Frequência angular: ω = √(k/m)

Período: T = 2π/ω

Parâmetros do Pêndulo

Equação: θ'' + (b/m)·θ' + (g/L)·sin(θ) = 0

Para ângulos pequenos: T ≈ 2π√(L/g)

Período exato depende da amplitude

Parâmetros do Lançamento

Equações do Movimento:

x(t) = v₀·cos(θ)·t

y(t) = h + v₀·sin(θ)·t - ½gt²

Alcance: R = (v₀²·sin(2θ))/g

Altura máxima: H = (v₀²·sin²θ)/(2g)
