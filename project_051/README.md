# TaskFlow

Quadro de tarefas em 3 colunas com prioridade, prazo, busca, filtro e progresso; dados no localStorage.

**Stack:** React + TypeScript + Tailwind CSS (CLI) + esbuild + Jest (lógica). Site estático: abra `index.html` (ou GitHub Pages); o bundle pronto está em `dist/`.

**Rodar:** sirva a raiz do portfólio (`python3 -m http.server 8080`) e abra `/project_051/index.html`.

**Buildar:** `npm install && npm run build` (código em `src/`, saída em `dist/`). **Testes:** `npm test`.
