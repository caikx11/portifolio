# 075 · Tinta UI (Biblioteca de componentes Tailwind)
TypeScript + Tailwind (CLI, CSS pré-compilado). Catálogo com botões (variante/tamanho/desabilitado), badges, alertas, modal acessível, tabs, toasts, accordion e campos de formulário. Cada seção mostra a prévia, o HTML e o botão **Copiar código**.

Os snippets em `src/snippets.ts` são a fonte única: o mesmo HTML é renderizado e copiado. As classes ficam literais para o Tailwind encontrá-las.

```
npm i && npm run build
```
