# Painel de Cripto (CriptoDeck)

Mercado simulado em tempo real com gráficos SVG próprios (linha/velas), favoritos e carteira de compra/venda simulada.

**Stack:** React + TypeScript + esbuild + Jest (lógica). Site estático: abra `index.html` (ou GitHub Pages); o bundle pronto está em `dist/`.

**Rodar:** sirva a raiz do portfólio (`python3 -m http.server 8080`) e abra `/project_052/index.html`.

**Buildar:** `npm install && npm run build` (código em `src/`, saída em `dist/`). **Testes:** `npm test`.
