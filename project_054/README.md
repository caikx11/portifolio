# Receitário

Receitas com busca, categorias, favoritas, ajuste de porções e lista de compras.

**Stack:** React + TypeScript + esbuild + Jest (lógica). Site estático: abra `index.html` (ou GitHub Pages); o bundle pronto está em `dist/`.

**Rodar:** sirva a raiz do portfólio (`python3 -m http.server 8080`) e abra `/project_054/index.html`.

**Buildar:** `npm install && npm run build` (código em `src/`, saída em `dist/`). **Testes:** `npm test`.
